## ADDED Requirements

### Requirement: Плагин находит иконку по имени

Плагин SHALL строить `ImageSource` для свойства типа `icon` из `literal`-строки payload — имени иконки в формате данных
(`disclosure.down.fill.16`), приводя его к члену `SddsIcons` (`DisclosureDownFill16`), — по реестру иконок `icons-compose`. Иконка MUST рисоваться тем же компонентом, что и в приложении, с цветом и отступом из стиля.

#### Scenario: Известное имя

- **WHEN** payload содержит `closedIcon` со значением `disclosure.down.fill.16`
- **THEN** билдер стиля MUST получить `ImageSource` этой иконки
- **AND** компонент MUST отрисоваться с иконкой.

#### Scenario: Неизвестное имя

- **WHEN** имя иконки отсутствует в реестре
- **THEN** билдер MUST сохранить значение по умолчанию, а результат MUST содержать предупреждение `unknown_icon` с путём к свойству
- **AND** render MUST NOT быть отклонён.

#### Scenario: Свойство иконки не задано

- **WHEN** payload не содержит свойства иконки
- **THEN** компонент MUST отрисоваться со значением иконки по умолчанию без предупреждений.
