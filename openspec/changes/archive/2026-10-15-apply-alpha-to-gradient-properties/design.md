## Context

`PreviewPropertyValue.brushValue(theme)` собирает `Brush` для цветовых свойств, у которых есть перегрузка с `Brush`:
для токена-градиента берётся `theme.gradient(id)`, для цвета `SolidColor`. Прозрачность источника (`alpha` у
`tokenRef`/`literal`) накладывает `applyAlpha`; для `SolidColor` он умножает альфу цвета, для остальных кистей
возвращает кисть без изменений. `PreparedComposeTheme` строит градиент из первого слоя токена (`ShaderBrush` через
`Gradients.Linear`).

## Decisions

1. **Градиент строится заново с прозрачностью.** `Brush` запечатан, а `ShaderBrush.applyTo` финальный, поэтому обернуть
   готовую кисть и умножить `alpha` при рисовании нельзя (проверено компиляцией). Вместо этого тема хранит первый слой
   каждого градиентного токена (`gradientLayers`) и строит кисть с множителем: `theme.gradient(id, alpha)` умножает альфу
   каждого цвета стопа (`withAlphaFactor`).
2. **Выбор значения с `alpha`.** `resolve` и `resolveStates` получают необязательный `tokenWithAlpha: (id, alpha) -> T?`.
   Если у токена задан `alpha` и такой разрешитель передан, значение строится им; иначе работает прежний путь
   `token` и `applyAlpha`. `brushValue` передаёт разрешитель, который берёт градиент с альфой, а для цветового токена
   сплошной цвет с альфой.
3. **Цвет и остальные типы не затрагиваются.** `SolidColor`, `colorValue`, `dpValue` и прочие работают как раньше.
4. **Единица `alpha`.** Множитель 0..1, как у сплошного цвета; значения вне диапазона отсекает клиент.

## Risks / Trade-offs

- Кисть строится при каждом разрешении значения с `alpha`; градиентов в теме единицы, поэтому цена мала.
- Как и раньше, для токена используется первый слой градиента.
