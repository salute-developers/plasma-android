## MODIFIED Requirements

### Requirement: Плагин находит иконку по имени

Плагин SHALL строить `ImageSource` для свойства типа `icon` из `literal`-строки payload — имени иконки в формате данных
(`disclosure.down.fill.16`) — по SVG-ресурсу payload с идентификатором `icon:<имя>` (точное совпадение имени). Иконка MUST
рисоваться тем же компонентом и с тем же тинтом, что и иконка по умолчанию.

#### Scenario: Известное имя

- **WHEN** payload содержит `closedIcon` со значением `disclosure.down.fill.16` и ресурс `icon:disclosure.down.fill.16` типа `SVG`
- **THEN** билдер стиля MUST получить `ImageSource` этой иконки
- **AND** компонент MUST отрисоваться с иконкой, закрашенной цветом содержимого компонента.

#### Scenario: Неизвестное имя

- **WHEN** в payload нет ресурса `icon:<имя>` для значения свойства иконки
- **THEN** билдер MUST сохранить значение по умолчанию, а результат MUST содержать предупреждение `unknown_icon` с путём к свойству
- **AND** render MUST NOT быть отклонён.

#### Scenario: Свойство иконки не задано

- **WHEN** payload не содержит свойства иконки
- **THEN** компонент MUST отрисоваться со значением иконки по умолчанию без предупреждений.

## ADDED Requirements

### Requirement: Иконки приходят SVG-ресурсами payload

Плагин SHALL загружать ресурсы `assets[]` с типом `SVG` и идентификатором, начинающимся с `icon:`, тем же `PreviewAssetResolver`,
что и шрифты, до подготовки темы, и разбирать их штатным SVG-модулем Skia. Плагин MUST NOT содержать собственный набор иконок
и MUST NOT зависеть от `sdds-icons-compose`. Размер плагина MUST NOT зависеть от числа иконок каталога.

#### Scenario: Иконка не из стартового набора

- **WHEN** payload содержит ресурс `icon:apps.outline-bold.16` с SVG, которого нет в Android-наборе иконок
- **THEN** компонент MUST отрисоваться с этой иконкой.

#### Scenario: Недоступный или битый файл

- **WHEN** SVG-ресурс иконки не скачивается (ошибка сети, HTTP-статус не 2xx) или не разбирается как SVG
- **THEN** иконка MUST быть пропущена и MUST получить предупреждение `unknown_icon`
- **AND** остальные иконки и компонент MUST отрисоваться, render MUST NOT быть отклонён.

#### Scenario: Ресурс не иконка

- **WHEN** ресурс не имеет префикса `icon:` или его тип не `SVG`
- **THEN** плагин MUST NOT регистрировать его как иконку.

#### Scenario: Повторный render

- **WHEN** следующий payload ссылается на те же адреса SVG
- **THEN** плагин SHOULD использовать закешенное содержимое без повторного скачивания.
