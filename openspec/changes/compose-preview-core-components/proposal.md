## Why

Compose preview сейчас умеет рисовать один компонент, `BasicButton`: для него вручную написаны фабрика стиля
(`BasicButtonPreviewStyleFactory`, около 100 строк) и запись в реестре плагина. В `uikit-compose` 79
компонентов с билдерами стилей и 74 истории (`@Story`) в `uikit-compose-fixtures`. Писать фабрику на каждый
компонент вручную нельзя: это сотни свойств и перегрузок билдеров, а правила выбора перегрузки уже
реализованы в Theme Builder и должны совпадать.

Шаги 1 и 2 плана ADR-0006 доставили плагин в браузер и расширили контракт (составные и кастомные состояния,
alpha, градиенты, вложенные стили, `spread` тени). Этот change использует новые возможности контракта и
доводит preview до всего Core-набора.

## What Changes

- **Реестр компонентов.**
  - Публичный перечислимый type-erased реестр историй: `componentId`, история, имя класса стиля.
  - `@Story` получает явный `componentId`; уникальность проверяется при сборке.
  - `components` в `preview-plugin.json` формируется из реестра и не пишется вручную.
- **Генерация фабрик стилей.**
  - Новый генератор читает `uikit-compose-api-meta.json` и для каждого компонента меты порождает фабрику стиля.
    Форма генератора (KSP-процессор в новом модуле `preview-ksp` или Gradle-задача с KotlinPoet) выбирается спайком, см. `design.md`. Мета подключается как Gradle-зависимость (ресурс артефакта `uikit-compose`), а не копией.
  - Выбор перегрузки билдера и оформление значения (`SolidColor`, `asStatefulValue`, `multiplyAlpha`, `asLayered`)
    записаны как спецификация и реализованы в генераторе заново; Theme Builder не меняется.
  - Вызовы билдеров по имени свойства порождаются как `when` (в Kotlin/Wasm нет рефлексии).
  - Поддержаны интерактивные и кастомные состояния компонента (`stateEnum` меты) и вложенные стили через `styleRef`.
- **Дифференциальный тест** сравнивает выбор вызова билдера в Theme Builder и в сгенерированной фабрике для одного
  конфига; тест покрытия сверяет число компонентов меты, историй и фабрик.
- **Плагин** собирает компоненты из реестра и сгенерированных фабрик; ручной `BasicButtonPreviewStyleFactory` удаляется.
- Фазы покрытия: A (простые), B (кастомные состояния), C (вложенные стили) входят в change. Фаза D (иконки и тени)
  зависит от painter'ов для SVG/PNG и вынесена за рамки (см. `design.md`); свойства иконок и теней игнорируются с предупреждением.

Публичный API затронут только совместимо: `@Story` получает необязательный `componentId`, `StoryRegistry` — перечисление,
`ComposePreviewStyleFactory` — члены с реализацией по умолчанию. Генератор не публикуется (используется только при сборке плагина).
Theme Builder, токены, docs generation и Gradle-конвенции приложений не затрагиваются.

## Capabilities

### New Capabilities

- `compose-preview-component-registry`: идентификаторы компонентов, перечислимый реестр историй, генерация списка
  компонентов для manifest.
- `compose-preview-style-generation`: генерация фабрик стилей по api-мете, правила выбора перегрузок, состояния,
  вложенные стили, проверки покрытия и соответствия Theme Builder.

### Modified Capabilities

- `compose-preview-sdk`: ручная фабрика BasicButton заменяется сгенерированными фабриками для всех компонентов;
  выбор истории обобщается с BasicButton на любой зарегистрированный компонент.

## Impact

- `integration-core/sandbox-core` (`@Story`, `StoryRegistry`), `integration-core/sandbox-ksp` (реестр),
  генератор фабрик (новый модуль `integration-core/preview-ksp` либо Gradle-задача в `preview-compose-plugin`), `integration-core/uikit-compose-fixtures` (аннотации), `integration-core/preview-sdk-compose`
  (type-erased сборка компонента, вложенные стили), `integration-core/preview-compose-plugin` (сборка из реестра, manifest).
- `sdds-core/uikit-compose`: только как источник api-меты (код не меняется); `sdds-core/plugin_theme_builder`: только чтение для теста
  соответствия (код не меняется).
- Размер Wasm-артефакта растёт: генерируются фабрики для 79 компонентов, подключаются 74 истории. Нужен замер до и после.
- Валидация: `./gradlew testAll detektAll spotlessApplyAll`, браузерный тест плагина `previewPluginBrowserTest`.
