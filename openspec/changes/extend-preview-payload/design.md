## Context

Парный change в DS Builder (`extend-preview-payload`) задаёт каноническую схему и фикстуры; подробные решения D1 и D7 этого change (расширение v1 на месте без повышения версии, состояния массивом наборов, источники, вложенные стили, единый владелец схемы) приведены там. Здесь описана реализация в контракте, SDK и плагине.

## Decisions

### D1. Контракт повторяет каноническую схему

Kotlin-модели `PreviewContract.kt` приводятся к расширенной схеме v1: `PreviewPropertyValue(base, states: List<PreviewStateEntry>)`, `PreviewStateEntry(when: Set<String>, source)`, sealed `PreviewPropertySource` с `Literal`, `TokenReference`, `StyleReference`, `AssetReference`, поле `styles`, токен `Gradient`, `spread` в слое тени, `PreviewResult.Success.warnings`. Копии схем и фикстур в `src/commonMain/resources/{schemas,fixtures}/v1` берутся побайтово из DS Builder; тест сравнения хэшей файлов с дайджестом (`schemas/v1/DIGEST`) ловит ручную правку.

### D2. Разрешение состояний в SDK

Выбор записи реализован чистой функцией «активные состояния и список записей → запись», чтобы его тестировать без Compose. Известные плагину имена состояний сопоставляются с UIKit (`pressed`, `hovered`, `focused`, `activated`, `selected`, `disabled`), остальные дают предупреждение.

### D3. Граф стилей проверяется до построения

Валидатор обходит `styleRef` и `assetRef` до сборки стиля (DFS с цветами вершин), чтобы отказ был атомарным.

### D4. SVG и PNG пока без painter

Плагин принимает ресурсы SVG и PNG, но не создаёт painter (вне scope); для них возвращается предупреждение `unsupported_asset`.

## Risks / Trade-offs

- [Ручная синхронизация схемы между репозиториями] → побайтовая проверка и дайджест в этом репозитории; сверка с каноническим файлом в DS Builder при релизе пары.
- [Хрупкость сопоставления имён состояний с UIKit] → тесты на каждое имя и предупреждение на неизвестные.

## Migration Plan

Изменения не требуют миграции данных. Перед проверкой пары пересобрать плагин, выложить его и обновить адрес в клиенте DS Builder. Откат: вернуться к предыдущей версии плагина и клиента.
