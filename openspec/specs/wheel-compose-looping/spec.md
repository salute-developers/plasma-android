## Requirements

### Requirement: WheelDataSet предоставляет поле looping
`WheelDataSet` SHALL предоставлять свойство `looping: Boolean = false`, определяющее, зациклена ли прокрутка конкретного колеса.
`WheelDataSet` SHALL сохранять обратную совместимость существующих Kotlin- и JVM-вызовов конструктора (значение по умолчанию `false`).

#### Scenario: looping по умолчанию выключен
- **WHEN** `WheelDataSet` создаётся без явного `looping`
- **THEN** `WheelDataSet.looping == false`

#### Scenario: looping сохраняется в dataset
- **WHEN** `WheelDataSet` создаётся с `looping = true`
- **THEN** `WheelDataSet.looping == true`

### Requirement: Зацикливание применяется к конкретному колесу, а не ко всему компоненту
`Wheel` SHALL позволять одновременно отображать колёса с `looping = true` и `looping = false` в рамках одного вызова с `wheelCount > 1`, где значение `looping` берётся из `WheelDataSet`, возвращённого `onSetData` для соответствующего индекса колеса.

#### Scenario: Одно колесо зациклено, другое — нет
- **WHEN** `Wheel(wheelCount = 2, onSetData = { index -> WheelDataSet(dataSet = ..., looping = index == 0) })` отображается
- **THEN** колесо с индексом `0` прокручивается без жёстких границ (может докрутить "после последнего" элемента к первому)
- **THEN** колесо с индексом `1` сохраняет текущее поведение — прокрутка останавливается на первом и последнем элементе `dataSet`

### Requirement: Looping-колесо прокручивается без жёстких границ
При `looping = true` `BaseWheel` SHALL позволять непрерывную прокрутку в обе стороны: после последнего элемента `items` следующим показывается первый, и наоборот.

#### Scenario: Прокрутка вперёд после последнего элемента
- **WHEN** колесо с `looping = true` прокручено так, что в центре находится последний элемент `items`
- **AND** пользователь продолжает прокрутку в том же направлении
- **THEN** следующим в центре оказывается первый элемент `items` (без остановки на границе)

#### Scenario: Прокрутка назад перед первым элементом
- **WHEN** колесо с `looping = true` прокручено так, что в центре находится первый элемент `items`
- **AND** пользователь прокручивает в обратном направлении
- **THEN** следующим в центре оказывается последний элемент `items` (без остановки на границе)

### Requirement: Ширина looping-колеса не зависит от зацикливания
При расчёте ширины колеса (когда ширина не задана извне явным ограничением) `BaseWheel` SHALL измерять текстовые метрики (`WheelTextMetrics`) только по реальному, немодифицированному списку `items`, независимо от значения `looping` и от того, как организована прокрутка.

#### Scenario: Ширина looping-колеса равна ширине такого же non-looping колеса
- **WHEN** два колеса созданы с одинаковым `items` и одинаковым внешним ограничением ширины, но одно с `looping = true`, другое с `looping = false`
- **THEN** итоговая рассчитанная ширина обоих колёс совпадает

#### Scenario: Расчёт ширины looping-колеса не деградирует по стоимости относительно non-looping колеса
- **WHEN** колесо с `looping = true` и колесо с `looping = false` созданы с одинаковым `items`
- **THEN** объём измеряемых при расчёте ширины элементов (количество текстовых intrinsic-измерений) для обоих колёс одинаков и равен размеру `items` (не зависит от числа возможных позиций прокрутки)

### Requirement: DataEdgePlacement не применяется к looping-колесу
При `looping = true` `BaseWheel` SHALL игнорировать значение `dataEdgePlacement`, переданное в `Wheel`, для этого колеса — дополнительные пустые (dummy) элементы по краям списка не добавляются.

#### Scenario: dataEdgePlacement передан, но колесо зациклено
- **WHEN** `Wheel(dataEdgePlacement = DataEdgePlacement.WheelCenter, ...)` отображает колесо с `WheelDataSet.looping = true`
- **THEN** список, по которому прокручивается это колесо, не содержит дополнительных пустых элементов по краям

### Requirement: Выбор текущего элемента корректен для looping-колеса
`BaseWheel` SHALL вызывать `onItemSelected` с индексом в диапазоне `[0, items.size - 1]`, соответствующим реальному элементу `items`, находящемуся в центре вьюпорта, независимо от того, сколько раз прокрутка обернулась вокруг списка.

#### Scenario: Индекс выбранного элемента корректен после многократного оборота
- **WHEN** колесо с `looping = true` прокручено на несколько полных оборотов списка `items` в одном направлении
- **THEN** `onItemSelected` получает индекс, соответствующий фактически отображённому в центре элементу `items`, а не накопленному виртуальному индексу прокрутки

### Requirement: Управляющие стрелки работают без остановки на границах для looping-колеса
При `hasControls = true` и `looping = true` `BaseWheel` SHALL позволять переход к следующему/предыдущему элементу в обе стороны без ограничения по первому/последнему индексу `items`.

#### Scenario: Стрелка "вниз" на последнем элементе списка
- **WHEN** в центре looping-колеса находится последний элемент `items`
- **AND** пользователь нажимает управляющую стрелку в сторону следующего элемента
- **THEN** колесо прокручивается к первому элементу `items`, кнопка остаётся активной (не блокируется)

#### Scenario: Стрелка "вверх" на первом элементе списка
- **WHEN** в центре looping-колеса находится первый элемент `items`
- **AND** пользователь нажимает управляющую стрелку в сторону предыдущего элемента
- **THEN** колесо прокручивается к последнему элементу `items`, кнопка остаётся активной (не блокируется)

### Requirement: Короткие списки допускают одновременную видимость дублей
При `looping = true` и `items.size < visibleItemsCount` `BaseWheel` SHALL корректно отображать колесо без ошибок или исключений, даже если один и тот же элемент `items` оказывается видимым одновременно в нескольких позициях вьюпорта.

#### Scenario: Список короче видимой области
- **WHEN** колесо создано с `looping = true`, `items.size = 2` и `visibleItemsCount = 5`
- **THEN** колесо отображается без исключений, элементы `items` циклически повторяются в видимой области вьюпорта
