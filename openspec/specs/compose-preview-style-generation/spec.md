## Requirements
### Requirement: Фабрика стиля генерируется для каждого компонента api-меты

Генератор SHALL читать `uikit-compose-api-meta.json` и для каждой записи меты (`componentName`, `qualifiedName` билдера,
`styleQualifiedName`, `params`) порождать фабрику `ComposePreviewStyleFactory`, которая строит стиль
через соответствующий билдер UIKit. Фабрики MUST собираться в карту `componentId` на фабрику. Способ реализации генератора
(KSP-процессор или Gradle-задача, пишущая исходники) определяется спайком и не меняет требований этой спеки.

#### Scenario: Фабрика создана для записи меты

- **WHEN** мета содержит запись `BasicButton` с `builderFunName = basicButtonBuilder` и `styleQualifiedName = ButtonStyle`
- **THEN** сгенерированная карта MUST содержать фабрику `BasicButton`, строящую `ButtonStyle` через `ButtonStyle.basicButtonBuilder()`.

### Requirement: Точка входа в билдер определяется по мете и соглашению

Генератор SHALL создавать билдер стиля так: если запись меты содержит `builderFunName`, вызывать эту функцию стиля
(`ButtonStyle.basicButtonBuilder()`); иначе вызывать `<Style>.builder()` из companion стиля. Функция MUST возвращать класс билдера,
указанный в `qualifiedName` записи. Запись, для которой точка входа не найдена, MUST приводить к ошибке сборки с именем компонента.
(На момент написания `builderFunName` задан у 5 из 79 записей: `Badge`, `BasicButton`, `IconBadge`, `IconButton`, `LinkButton`;
у остальных 74 в исходниках есть `fun builder(...)` с нужным типом билдера.)

#### Scenario: Именованная точка входа

- **WHEN** запись содержит `builderFunName`
- **THEN** фабрика MUST вызвать именно эту функцию, потому что один класс стиля может иметь несколько билдеров (`ButtonStyle` имеют три записи меты).

#### Scenario: Точка входа по соглашению

- **WHEN** запись не содержит `builderFunName`
- **THEN** фабрика MUST вызвать `<Style>.builder()` (например, `CheckBoxStyle.builder()`).

#### Scenario: Точка входа не найдена

- **WHEN** для записи нет ни `builderFunName`, ни функции `builder()`, возвращающей нужный билдер
- **THEN** сборка MUST завершиться ошибкой с именем компонента и ожидаемым типом билдера.

#### Scenario: Генерация детерминирована

- **WHEN** процессор запускается дважды на одной мете
- **THEN** результаты MUST совпадать побайтово.

### Requirement: Мета подключается как зависимость сборки

Api-мета SHALL подключаться к генератору как ресурс артефакта `uikit-compose` через Gradle-зависимость. Копия
файла в репозитории MUST NOT создаваться.

#### Scenario: Версия меты совпадает с версией UIKit

- **WHEN** обновляется версия `uikit-compose`
- **THEN** при следующей сборке плагина фабрики MUST порождаться по мете новой версии без ручного копирования.

#### Scenario: Мета недоступна

- **WHEN** ресурс меты не найден или не парсится
- **THEN** сборка MUST завершаться ошибкой с путём ресурса.

### Requirement: Выбор перегрузки билдера следует фиксированным правилам

Для свойства с несколькими перегрузками билдера генератор SHALL выбирать перегрузку по приоритету параметра:
`StatefulValue`, затем `InteractiveColor`, затем обычный тип значения. Для свойства, значение которого может быть
градиентом, MUST выбираться только перегрузки с `Brush`. Если подходящей перегрузки нет, свойство MUST быть
помечено как неподдержанное.

#### Scenario: Приоритет StatefulValue

- **WHEN** у свойства есть перегрузки с `CornerBasedShape` и `StatefulValue<CornerBasedShape>`
- **THEN** генератор MUST вызывать перегрузку со `StatefulValue`.

#### Scenario: Градиент

- **WHEN** payload передаёт для цветового свойства токен `gradient`
- **THEN** вызываться MUST только перегрузка с `Brush`
- **AND** если такой перегрузки нет, свойство MUST быть пропущено с предупреждением `unsupported_property`.

#### Scenario: Свойство без подходящей перегрузки

- **WHEN** ни одна перегрузка свойства не принимает значение того вида, который пришёл в payload
- **THEN** фабрика MUST пропустить это значение с предупреждением `unsupported_property`
- **AND** сборка MUST завершаться ошибкой, только если у свойства меты нет перегрузки ни для одного из поддержанных видов значения.

### Requirement: Значение оформляется под тип параметра по фиксированным правилам

Перед вызовом билдера генератор SHALL приводить разрешённое значение к типу параметра: цвет в `Brush` через
`SolidColor`, значение в `StatefulValue` через `asStatefulValue` либо набор состояний, прозрачность токена цвета
через `multiplyAlpha`, слои цвета через `asLayered`. Правила MUST совпадать с правилами Theme Builder для той же пары
«тип параметра, тип значения».

#### Scenario: Цвет в Brush

- **WHEN** параметр принимает `Brush`, а значение это цвет `#112233FF`
- **THEN** билдеру MUST передаваться `SolidColor` этого цвета.

#### Scenario: Alpha токена

- **WHEN** источник значения `tokenRef` содержит `alpha: 0.4`
- **THEN** итоговый цвет MUST иметь альфа-канал, умноженный на 0.4.

### Requirement: Вызовы билдера порождаются без рефлексии

Фабрика SHALL вызывать методы билдера прямым сгенерированным кодом, выбирая метод по `id` свойства оператором `when`.
Фабрика MUST NOT использовать рефлексию, поиск методов по имени во время выполнения или разбор строк.

#### Scenario: Диспетчеризация по id

- **WHEN** payload содержит свойство `backgroundColor`
- **THEN** фабрика MUST вызвать метод билдера, указанный в мете для `id = backgroundColor`.

#### Scenario: Неизвестное свойство

- **WHEN** payload содержит свойство, которого нет в мете компонента
- **THEN** фабрика MUST пропустить его, оставив значение по умолчанию билдера.

### Requirement: Состояния сопоставляются с UIKit и кастомными состояниями компонента

Фабрика SHALL сопоставлять имена состояний записи `when` с интерактивными состояниями UIKit (`pressed`, `hovered`,
`focused`, `activated`, `selected`) и со значениями `stateEnum` меты компонента. Имя кастомного состояния в протоколе
MUST сопоставляться с `configName` константы `stateEnum` (по умолчанию имя константы) без учёта регистра (`checked` и `Checked` дают `CheckBoxStates.Checked`),
как в Theme Builder; имена интерактивных состояний UIKit сопоставляются точно. Запись, содержащая
неизвестное имя, MUST пропускаться с предупреждением `unknown_state`. Если несколько записей подходят, SHALL
действовать правило выбора Preview Protocol (больше имён побеждает, при равенстве последняя).

#### Scenario: Кастомное состояние CheckBox

- **WHEN** CheckBox получает запись `when: ["checked"]` для цвета рамки
- **THEN** фабрика MUST связать значение с состоянием `CheckBoxStates.Checked`.

#### Scenario: Регистр имени кастомного состояния

- **WHEN** запись содержит `when: ["Indeterminate"]` либо `when: ["indeterminate"]`
- **THEN** фабрика MUST связать значение с `CheckBoxStates.Indeterminate` и MUST NOT добавлять предупреждение `unknown_state`.

#### Scenario: Составное состояние

- **WHEN** запись содержит `when: ["pressed", "checked"]`
- **THEN** значение MUST применяться только при одновременно активных состояниях.

#### Scenario: Неизвестное состояние

- **WHEN** запись содержит `when: ["fancy"]`
- **THEN** запись MUST быть пропущена и результат MUST содержать предупреждение `unknown_state` с путём к записи.

### Requirement: Вложенные стили строятся рекурсивно

Для параметра меты типа `component_style` фабрика SHALL получать значение из `styleRef`: стиль берётся из
`payload.styles`, его фабрика определяется полем `component` стиля, результат подставляется в параметр родительского
билдера. Тип построенного стиля MUST совпадать с типом параметра.

#### Scenario: Вложенный стиль построен

- **WHEN** свойство `dividerStyle` ссылается на стиль компонента `Divider`
- **THEN** фабрика родителя MUST построить `DividerStyle` фабрикой `Divider` и передать его в билдер.

#### Scenario: Тип вложенного стиля не совпадает

- **WHEN** стиль, на который ссылается свойство, принадлежит компоненту с другим типом стиля
- **THEN** SDK MUST вернуть `PreviewResult.Failure` с кодом `style_type_mismatch` и путём к свойству.

#### Scenario: Стиль компонента без фабрики

- **WHEN** `styleRef` указывает на стиль, у компонента которого (`PreviewStyle.component`) нет сгенерированной фабрики
- **THEN** SDK MUST вернуть `PreviewResult.Failure` с кодом `style_component_not_found` и путём к свойству
- **AND** проверка MUST выполняться до построения стиля и отрисовки.

#### Scenario: Общий вложенный стиль

- **WHEN** два свойства ссылаются на один стиль
- **THEN** стиль MAY строиться один раз и использоваться повторно.

### Requirement: Устаревшие свойства и несоответствующие перегрузки пропускаются

Генератор SHALL пропускать свойства, помеченные `@ApiDeprecated` (поле `deprecated` меты), как это делает Theme Builder. Генератор MUST
пропускать перегрузки, у которых тип значения не соответствует виду свойства (например, свойство `dimensions` у `AvatarGroup` имеет вид `dimension`,
но принимает объект `AvatarGroupDimensions`, а не `Dp`).

#### Scenario: Устаревшее свойство

- **WHEN** запись меты содержит `deprecated`
- **THEN** фабрика MUST NOT вызывать соответствующий метод билдера.

#### Scenario: Несоответствующий тип значения

- **WHEN** перегрузка вида `dimension` принимает не `Dp`
- **THEN** генератор MUST NOT порождать для неё вызов, а сгенерированный код MUST компилироваться.

### Requirement: Генератор соответствует Theme Builder

Тест SHALL сравнивать для каждого свойства каждого компонента api-меты выбор перегрузки билдера (имя метода, тип параметра, группа),
который делает Theme Builder (`UniversalComposeVariationGenerator.selectOverload`), и выбор генератора фабрик, отдельно для сплошного
цвета и для градиента. Тест MUST использовать классы Theme Builder, а не копию его правил. Расхождение MUST приводить к падению теста.

#### Scenario: Совпадающий выбор

- **WHEN** тест прогоняет мету через оба пути
- **THEN** для каждого свойства выбор перегрузки MUST совпадать.

#### Scenario: Оформление значения

- **WHEN** выбранная перегрузка принимает `Brush`, `InteractiveColor`, `Color` либо `StatefulValue`
- **THEN** правила оформления значения (`SolidColor`, `asInteractive`, `asStatefulValue`, прозрачность) MUST соответствовать правилам Theme Builder; оформление проверяется выборочными тестами фабрик на компонентах каждого вида.

#### Scenario: Расхождение

- **WHEN** правило выбора изменено только в одном из путей
- **THEN** тест MUST упасть с именем свойства и обеими перегрузками.

### Requirement: Покрытие компонентов проверяется

Тест SHALL сверять набор компонентов api-меты, набор историй реестра и набор сгенерированных фабрик. Компонент меты
без фабрики, фабрика без записи меты и история без фабрики MUST быть перечислены в явном списке исключений с причиной;
неперечисленное расхождение MUST приводить к падению теста.

#### Scenario: Все компоненты учтены

- **WHEN** тест выполняется на текущей мете и реестре
- **THEN** каждая история реестра и каждый компонент меты MUST иметь фабрику, запись реестра или исключение с причиной.

#### Scenario: Новый компонент без фабрики

- **WHEN** в мету добавлен компонент, для которого генерация не создала фабрику
- **THEN** тест MUST упасть с именем компонента.

### Requirement: Браузерная галерея отрисовывает каждый зарегистрированный компонент

Браузерный тест плагина SHALL для каждого компонента из `components` manifest собирать payload из api-меты (для каждого свойства
подставляется пробное значение подходящего вида: цвет, размер, форма, типографика, состояния, перечисления, вложенный стиль),
отправлять его в production-артефакт плагина в headless Chrome и проверять результат. Тест MUST сохранять скриншот каждого
компонента и собирать из них одну HTML-страницу для просмотра. Артефакт плагина MUST содержать Compose-ресурсы историй
(`composeResources`), иначе истории, использующие ресурсы, не отрисуются.

#### Scenario: Все компоненты отрисованы

- **WHEN** галерея прогоняет все компоненты manifest
- **THEN** каждый payload MUST получить `PreviewResult.Success`
- **AND** набор предупреждений MUST быть пустым (иконки и тени в payload галереи не передаются)
- **AND** скриншот каждого компонента MUST содержать более одного цвета (холст не пустой)
- **AND** страница не должна сообщать об исключениях (ошибки композиции приходят не результатом, а исключением страницы).

#### Scenario: Компонент не отрисовался

- **WHEN** хотя бы один компонент вернул `Failure`, предупреждение, пустой кадр, исключение страницы или три одинаковых кадра подряд
  (признак остановки рендера)
- **THEN** тест MUST упасть и перечислить все такие компоненты с причинами, а не только первый.

#### Scenario: Страница для просмотра

- **WHEN** галерея завершена
- **THEN** в каталоге результатов сборки MUST лежать HTML-страница со скриншотами всех компонентов и подписями `componentId`.

### Requirement: Выборочное сравнение с эталонным стилем

Для одного компонента каждой фазы (A, B, C) тест SHALL сравнивать стиль, построенный сгенерированной фабрикой по payload, со стилем,
собранным в тесте прямым вызовом билдера UIKit с теми же значениями, без помощников SDK. Сравнение MUST выполняться по поведению стиля
(значения по умолчанию и `getValue` для наборов состояний), а не по внутреннему представлению. Набор проверок MUST включать прозрачность
токена, составное состояние и две записи для одного набора состояний (побеждает последняя).

#### Scenario: Совпадение с эталоном

- **WHEN** payload и эталонный стиль кодируют одни и те же значения
- **THEN** значения стиля и результат `getValue` для каждого набора состояний MUST совпадать.

#### Scenario: Расхождение

- **WHEN** фабрика применяет значение иначе, чем прямой вызов билдера (прозрачность, порядок записей, состояние)
- **THEN** тест MUST упасть с названием компонента и свойства.

### Requirement: Свойства иконок порождают вызовы билдера

Генератор SHALL порождать для свойства меты типа `icon` вызов билдера по перегрузке с `ImageSource`, получая значение через
`iconValue()`. Свойство `icon` MUST NOT попадать в `unsupportedProperties`.

#### Scenario: Свойство иконки в мете

- **WHEN** мета содержит свойство типа `icon` с перегрузкой `ImageSource`
- **THEN** сгенерированная фабрика MUST вызывать соответствующий метод билдера
- **AND** устаревшая перегрузка с идентификатором ресурса MUST быть пропущена.

### Requirement: Тени вне покрытия этого change

Свойства меты типа `shadow` SHALL игнорироваться: билдер сохраняет значение по умолчанию, результат содержит предупреждение
`unsupported_property` с путём к свойству. Эти свойства MUST NOT приводить к ошибке render.

#### Scenario: Компонент с тенью

- **WHEN** payload содержит свойство тени
- **THEN** компонент MUST отрисоваться со значением тени по умолчанию
- **AND** результат MUST содержать `unsupported_property`.
